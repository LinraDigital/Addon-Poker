# LD - Poker 1.0.1

Texas Hold'em No Limit dans une taverne, entre joueurs proches (ou seul contre des bots). Les pièces d'or sont **fictives** : aucun or réel n'est échangé.

## Fonctionnalités
- Jusqu'à 7 joueurs, bots disponibles, pots annexes, abattage complet.
- Bourse fictive par personnage, avec prêt de l'aubergiste.
- Option « joueurs proches » (environ 28 m).
- Bouton de minimap, fenêtre déplaçable, aide avec le classement des mains.
- Français et anglais.

## Commandes
- `/poker` : ouvrir / fermer la table
- `/poker scale 0.9` : taille de la fenêtre
- `/poker reset` : remettre la bourse à 1 000 PO

## Compatibilité
Interface 16001. Dossier à copier dans `Interface\AddOns\LD_Poker`.
